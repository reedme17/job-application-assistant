# 求职申请助手 Skill

用于 Codex：整理用户提供的岗位搜索结果或链接，提取真实申请入口、微调简历、填写申请表，停在最终提交前。

## 换电脑使用

把整个 `job-application-assistant` 文件夹复制到另一台电脑。可以直接在 Codex 中指定这个文件夹里的 `SKILL.md`，让它读取并执行；若希望作为个人技能被自动发现，将文件夹放进该电脑配置的 Codex skills 目录（通常为 `~/.codex/skills/`）。打开新任务后确认技能可用。

目标电脑需要可用的浏览器操作工具及其权限，并由用户在实际受控的浏览器会话中登录。这个包不安装浏览器工具，也不携带登录状态。只有 Skill 文件、没有浏览器操作能力时，仍可处理提供的 JD 和简历，但不能自动操作网页。

## 自带 PDF 读写工具

`scripts/resume_pdf.py` 提供依赖检测、逐页文本提取、可选 OCR、从可编辑 JSON 生成 PDF、文本完整性检查和逐页预览。Codex 负责根据 JD 修改 JSON 中的真实经历，再用脚本生成新 PDF；原文件不会被覆盖，不保证复刻原版式。

需要 Python 3.10+、`scripts/requirements.txt` 中的 Python 包，以及用于预览的 Poppler。扫描件 OCR 另外需要 Tesseract。中文简历需提供覆盖相应文字的 TrueType 字体。依赖不会随 Skill 自动安装，首次运行由 Codex 检测并按目标电脑环境配置。

在 Skill 文件夹中运行 `python3 scripts/resume_pdf.py doctor` 检查环境。完整命令和安装方法见 `references/pdf-tools.md`。DOCX 输出仍需单独的文档工具。

## 开始

把基础简历放在单独的私有工作文件夹中。复制 `assets/profile-template.json` 到该工作文件夹，填写已确认的信息；可让 Codex 根据简历帮你初始化。无需一次填完所有资料，未知信息保持 null。

示例请求：

> 使用 $job-application-assistant。我的基础简历和个人资料在这个文件夹，搜索结果在我指定的浏览器标签页。先整理当前页的岗位，按我的偏好筛选，再逐个准备简历和填写申请表，最终提交由我完成。

如果 Skill 没被自动识别，可以改为：

> 读取这个文件夹中的 SKILL.md，并按照里面的流程处理我提供的职位链接和基础简历。

生成内容保存在单独的 `job-search-workspace` 或你指定的目录：队列、每个岗位的 JD、定制简历、修改记录、表单答案及处理状态。再次运行时让 Codex 从已有队列继续，避免重复处理。迁移进行中的工作需要额外复制这个私有工作目录；浏览器表单需重新打开检查。

## 实际边界

LinkedIn、Indeed 对第三方自动读取和填写本身也有限制；只让用户点最后一次 Submit，并不能消除这些限制。Skill 会使用允许的访问方式；不能自动读取的来源，需要你提供允许获取的职位链接或 JD。外部 ATS 是否能填写取决于网站规则、实际表单和浏览器工具，不能保证覆盖所有网站。

遇到验证码、登录验证、未知必填答案会保存进度并交给你处理。上传和自动保存可能在最终提交前向招聘方发送资料。简历只调整表达和排序，不补造事实。所有岗位均保留人工最终提交。

PDF 工具应通过随包的 `scripts/test_resume_pdf.py` 验证。真实账户投递与跨电脑浏览器兼容性未实测；PDF 自动检查不能代替逐页目视检查。
